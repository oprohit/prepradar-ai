# Final Demo Checklist

Before declaring the project demo-ready:

1. Start the application from a clean state.
2. Navigate the primary user journey as a first-time user.
3. Test the happy path.
4. Test at least one invalid input.
5. Test a relevant AI/API failure or simulated failure where practical.
6. Verify recovery behavior.
7. Inspect browser console.
8. Inspect failed network requests.
9. Verify intended presentation resolution.
10. Verify mobile/responsive behavior when relevant.
11. Verify deployed application separately from localhost.
12. Run demo-critic.
13. Fix every high-impact issue that can realistically be fixed within remaining time.
14. Re-run the primary demo journey after fixes.
15. Produce/update DEMO.md containing the exact presentation flow.
16. Ensure the first 30 seconds communicate the problem and value clearly.
17. Ensure the demonstration reaches the core result quickly.
18. Ensure no hidden manual intervention is required during the main demo.
19. Ensure reset/recovery is available if appropriate.
20. Ensure no raw API errors, broken links, placeholder UI or debug panels are visible.

Never claim "demo ready" based only on static code inspection.
