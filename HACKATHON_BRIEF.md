# Hackathon Brief

## Theme
Reimagine Placement Preparation

## Event / Host
GDGoC-CIT (Google Developer Groups on Campus - CIT) — Founders x GenAI Innovation Hackathon

## Rules
- $0 cost architecture enforced across all APIs and deployments.
- Real, demonstrable working user journey.
- Meaningful GenAI application (no pure chatbot wrappers).
- Deployed on public URL (Vercel) + GitHub repository.

## Judging Rubric
1. **Problem Alignment & User Value**: Solves the actual student confusion of what to prepare, how to prepare, current standing, and what to improve.
2. **Technical Depth & Meaningful AI**: Multimodal / structured GenAI for diagnostic evaluation, gap analysis, and real-time feedback.
3. **Personalization**: Two different students must receive differentiated plans based on target company/role, diagnostic scores, and skill gaps.
4. **Measurable Improvement**: Quantified Placement Readiness Index (PRI), topic mastery deltas, and live re-evaluation.
5. **UI/UX Excellence & WOW Factor**: Clean, intuitive interface making the value proposition obvious in <5 seconds.

## Problem Statement
Every student prepares for placements differently, but many struggle to understand:
1. What to prepare
2. How to prepare
3. Where they currently stand
4. What they need to improve

Your challenge is to build an innovative solution that helps students prepare better for placements.

## The Goal
Help students become better prepared for their placements through a structured, personalized journey:
STUDENT → ASSESS → UNDERSTAND CURRENT LEVEL → IDENTIFY GAPS → GET PERSONALIZED PLAN → PRACTICE → RECEIVE FEEDBACK → TRACK IMPROVEMENT → REASSESS → BECOME MORE PLACEMENT-READY.
